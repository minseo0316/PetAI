Project Overview

Pet.AI는 사용자가 업로드한 반려동물의 사진과 증상을 분석하여 초기 건강 조언을 제공하는 AI 웹 애플리케이션입니다.

  • Google Gemini 기반 멀티모달 분석
  • 개인화된 건강 기록 관리
  • 실시간 AI 영양 상담 챗봇

  • • 이미지 분석 결과에서 키워드 추출
  • • 질병 DB에서 관련 의학 정보 검색 (Context Retrieval)
  • • 프롬프트 엔지니어링으로 할루시네이션 최소화

Core Features

사용자를 위한 핵심 기능

RAG 기반 정밀 분석

AI의 창의성과 DB의 정확성을 결합하여 신뢰도 높은 조언을 제공합니다.

// Prompt Engineering Structure
[SYSTEM] 당신은 수의학 AI 전문 조수입니다.
[CONTEXT] (DB 검색됨) 피부염 증상: 붉은 발진, 가려움...
[USER] 고양이가 계속 긁어요. (이미지 첨부)
[RESPONSE] 검색된 증상과 이미지를 대조해 볼 때 알레르기가 의심됩니다...

개인화 기록 관리

반려동물별 프로필을 생성하고, 날짜별 건강 상태 변화를 히스토리로 관리합니다.

AI 영양상담 챗봇

단순 질의응답을 넘어, 반려동물의 상태에 맞는 사료와 영양제를 추천하는 대화형 에이전트입니다.
